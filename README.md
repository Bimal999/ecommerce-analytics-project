# E-Commerce Analytics Project

## Overview

This project analyzes a large-scale e-commerce dataset containing over 1 million transactions. The objective is to build an end-to-end analytics solution using:

* Python
* PostgreSQL
* SQL
* Power BI
* Machine Learning
* Git & GitHub

## Project Architecture

Business Understanding
→ Data Profiling
→ Data Quality Assessment
→ Data Modeling
→ PostgreSQL Data Warehouse
→ ETL Pipeline
→ SQL Analytics
→ Power BI Dashboard
→ Machine Learning

## Dataset

* Records: ~1,000,000+
* Columns: 62
* Domain: E-Commerce Analytics

Note: Raw dataset files are excluded from GitHub because they exceed GitHub's file size limits.
